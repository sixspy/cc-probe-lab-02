# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 分指标质控门槛（已落地）

不同指标各取自己的上下限，**门槛表与入栏同票**：裁决唯一出处 `校验.分门槛裁决`。

- 分指标门槛键：`门槛:<指标>:下限` / `门槛:<指标>:上限`；基线 PM25 另兼容 `PM25下限/上限`。
- 未配置门槛的指标**显式放行并打标**，绝不套用他指标默认阈。
- 错指标阈值点（报文声明门槛指标键与本指标不符）：正式不入栏，只进**只读影子归档**。
- 改门槛即推**账册版本**并钉**门槛指纹**；旧指纹命运在结栏时拒回刷，转影子归档。
- 装载 / 改门槛 / 结栏同经 `串行写`（`BEGIN IMMEDIATE`）写锁；同版争用只有一路成，不双写、不半分流。
- 只读接口：`GET /api/分门槛裁决?指标键=&读数=`（不写库、不推进版本）；另见 `/api/门槛账册`、`/api/影子归档`。
- 贯验只对正式轨（已汇总 == 汇总报文数）；影子草稿单列，不并入正式对账。

| 新增测试（先红后绿） | 验的是什么 |
| --- | --- |
| `tests/test_gate_split_a.py` | 错指标阈值下正式入栏不增、同一读数分指标分流、按指标取阈、只读裁决不写库 |
| `tests/test_gate_split_b.py` | 影子草稿不进正式对账、旧指纹命运拒回刷进影子 |
| `tests/test_gate_split_c.py` | 同版争用只成一路不双写、装载与结栏并发不半分流 |

并发双请求实测：`python tests/并发双请求脚本.py http://127.0.0.1:8120`（先起服务）。
